# structure-quantity｜結構數量計算子專案

依 IFC、結構平面圖、配筋圖及標準圖，計算柱、梁、板與 RC 牆數量，輸出依種類、樓層分工作表的 Excel。

## 目前狀態

尚未取得來源檔，現有 Excel 為待填範本，沒有實際工程數量。空白表示未計算，不代表零。使用者已確認混凝土以體積 m³ 計量。

## 來源與判定

- IFC：柱、梁、板、牆的幾何、樓層、構件編號與 GUID；須檢查模型單位、版本、重複構件及數量屬性是否可信。
- RC 牆：以使用者指定的「輕隔間TYPE-工地整理」DXF 中 RC 牆圖層為主；需取得實際圖層名稱、單位與座標對應。不可直接將所有 IfcWall 或輕隔間納入 RC 牆。
- 結構平面圖：確認樓層、構件定位、斷面尺寸、開口與模型差異。
- 配筋圖、標準圖：確認主筋、箍筋、分布筋、間距、分區、保護層、錨定、搭接、彎鉤與續接器。
- 衝突或缺漏列入待確認事項，保留來源、版本、圖號及核定紀錄，不自行填入推估實算值。

## Excel 結構

1. 說明：計量範圍與狀態。
2. 來源清單：版本、圖號、單位與來源位置。
3. RC牆圖層：DXF 圖層與 IFC 構件對應及覆核狀態。
4. 樓層彙總：樓層 × 柱／梁／板／RC牆的模板 m²、混凝土 m³。
5. 鋼筋彙總：樓層 × 構件種類 × 鋼筋號數的長度與重量 kg。
6. 構件明細：每個樓層各有柱、梁、板、RC牆工作表，記錄 GUID、尺寸、計算式、扣除量與淨量。
7. 鋼筋明細：每層記錄構件、筋別、號數、支數、單支長、總長、單位重及重量。
8. 待確認：問題、影響範圍、來源及處理狀態。

模板按實際接觸面計算，須確認交接面、開口及施工界面扣除規則；混凝土須確認柱梁板牆交疊的歸屬與扣除規則。鋼筋重量依核定號數單位重 × 計算長度，不以混凝土量乘經驗配筋率代替。以上規則確認後再實作數量擷取與自動計算。

## 產生範本

需要 Python 3 與 openpyxl：

```bash
python -m pip install -r requirements.txt
python scripts/create_template.py --output outputs/結構數量_待填範本.xlsx
# 取得實際樓層名稱後，為每個樓層產生分表：
python scripts/create_template.py --floors B1F 1F 2F RF --output outputs/結構數量_待填範本.xlsx
```

範例樓層只示範操作，不代表本案樓層。來源圖說與模型可能涉及專案資料，不應直接提交至公開儲存庫；以可授權存取的來源位置與版本清單追蹤。
